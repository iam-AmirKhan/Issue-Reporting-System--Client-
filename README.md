# InfraCare - Public Infrastructure Issue Reporting System

InfraCare is a digital platform that enables citizens to report public issues and tracks them through a professional municipal workflow.

### 🌐 Live Links
- **Live Site**: [https://public-issue-client.vercel.app](https://public-issue-client.vercel.app)
- **Admin Email**: `admin@infracare.com`
- **Admin Password**: `Admin@123`

---

### ✨ Key Features (10+)
1.  **3-Role System**: Admin, Staff, and Citizen dashboards.
2.  **Interactive Timeline**: Real-time tracking of issue progress.
3.  **Workforce Dispatch**: Admin modal for assigning staff to issues.
4.  **Priority Boosting**: Integrated payments to highlight urgent reports.
5.  **Premium Subscription**: Paid access for unlimited issue reporting.
6.  **Revenue Analytics**: Admin dashboard with payment statistics and charts.
7.  **PDF Invoices**: Downloadable receipts for all transactions.
8.  **Server-Side Search**: Search by name, category, or location.
9.  **Community Upvoting**: Collective prioritization of infrastructure needs.
10. **Automated Audit Logs**: Read-only history of all system actions.
11. **Responsive UI**: Premium design built with Tailwind and Framer Motion.
